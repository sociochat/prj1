# Waterproofing Services Website

A professional waterproofing services website built with React, TypeScript, and Tailwind CSS.

## Features

- Modern, responsive design
- Service showcase
- Client portfolio
- Project listings
- Contact information

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Technologies

- React 18
- TypeScript
- Tailwind CSS
- React Router
- Vite
